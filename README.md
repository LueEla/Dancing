Это проект по обучению танцам сальса Нью-Йорк и ча-ча-ча. 
Внутри этого проекта лежат видео-резюме с уроков школы танцев Ritmico. Преподаватели Гижэ, Алекс, Матан и Паз
В проекте нужно распределить видео в хронологическом порядке, добавить к ним описане с точной последовательностью элементов и связок. Это должна быть страница с удобным просмотром видео, с распределением на разделы по стилям и тд.
